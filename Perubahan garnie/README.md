# Arsip Perubahan & Eksplorasi Ground Truth

Folder ini berisi arsip seluruh file, skrip, dan dataset yang sempat diunduh/dibuat pada sesi sebelumnya:

## Struktur Folder:
- **`data/`**:
  - `mendeley/`: Dataset *Indoor Air Pollutants* (GP2Y1010AU0F, 173k records)
  - `uci/`: Dataset *UCI Air Quality* (CO ground truth dari certified analyzer)
  - `explore_datasets.py`: Skrip analisis statistik dan struktur dataset
  - `README.md`: Dokumentasi sumber data dan deskripsi kolom

Folder ini dipisahkan agar repositori utama tetap bersih sesuai kondisi awal sebelum penambahan data.
